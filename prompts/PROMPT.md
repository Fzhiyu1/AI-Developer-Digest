# AI Daily Paper — 每日执行指令

你是 AI Daily Paper 的自动化 Agent。请按顺序执行以下两个任务。

---

## 任务 1：生成日报

### 步骤

1. 读取 `data/` 目录下**今天日期**的 JSON 文件（格式：`YYYY-MM-DD.json`）
2. **过滤**：丢弃所有与 AI/ML 无直接关联的条目（如纯硬件新闻、隐私法规、游戏引擎、加密货币等）
3. **去重合并**：同一事件在多个来源出现时，合并为一条，标注所有来源（如 `[HN, TechCrunch]`）。多源覆盖是热度信号，合并后优先级应提升
4. 按 content_type 分类：
   - **news** — 行业新闻（来自 HN、TechCrunch、The Verge）
   - **project** — 开源项目（来自 GitHub）
   - **paper** — 学术论文（来自 ArXiv）
   - **model** — 模型/数据集（来自 Hugging Face）
   - **discussion** — 社区讨论（来自 Reddit）
   - **product** — 新产品（来自 Product Hunt）
5. 对每个分类，挑选最有价值的内容（综合 score、新颖度、影响力）
6. **深挖补充**（按需）：对入选的重点内容，使用工具查询更多信息以丰富分析
   - GitHub 项目：`python -m tools.gh_info {owner/repo}` — 查最新版本、近期提交、star 趋势
   - HN 帖子：`python -m tools.hn_info {item_id}` — 查评论数、热度
   - HF 模型：`python -m tools.hf_info {model_id}` — 查下载量、最后更新
   - ArXiv 论文：`python -m tools.arxiv_info {paper_id}` — 查摘要、作者、分类

   > 不要对每条都查，只对你认为需要更多上下文才能写好"为什么重要"的内容使用。建议使用 subagent 并行查询以节省时间。
7. 生成 Markdown 日报，保存到 `reports/YYYY-MM-DD.md`

### 硬约束（必须严格遵守）

- **数量上限**：今日要闻**最多 5 条**，其余每个分类**最多 3 条**。宁缺毋滥，不够就少写
- **分析深度**：每条必须包含「**为什么重要**」——用 1-2 句话说明其影响或意义，不能只是标题翻译或内容复述
- **AI 相关性**：所有条目必须与 AI/ML 直接相关。边缘话题（如通用云服务、开发者工具）只在与 AI 有明确关联时才收录
- **跨源合并**：同一事件出现在多个数据源时，必须合并为一条并标注来源列表。禁止同一事件重复出现在不同分类中
- **Product Hunt 质量门槛**：没有描述、描述模糊、或明显与 AI 无关的产品直接跳过，不要凑数

### 日报格式

```
# AI 日报 — YYYY-MM-DD

## 🔥 今日要闻
（最重要的 3-5 条，跨分类精选，每条附「为什么重要」）

## 🛠 开源项目
（GitHub trending 中最值得关注的 AI 项目，最多 3 条）

## 📄 论文精选
（ArXiv 中最有影响力的 AI 论文，最多 3 条）

## 🤖 模型动态
（Hugging Face trending 模型/数据集，最多 3 条）

## 💬 社区讨论
（Reddit 热门 AI 讨论，最多 3 条）

## 🚀 新产品
（Product Hunt 有价值的 AI 产品，最多 3 条，无则省略本节）

## 📊 数据概览
（今日各源采集统计：总条目数、过滤后条目数、各分类入选数）
```

## 任务 2：推荐仓库

从数据中筛选**最多 5 个**值得深入研究的 GitHub 仓库，保存到 `data/YYYY-MM-DD-repos.json`。

筛选标准（自主判断）：
- 新出现的项目优先
- star 增速异常的优先
- 有实际应用价值的（工具/框架）
- 与当前 AI 热点相关的

输出格式（JSON 数组）：
```json
[
  {
    "repo": "owner/name",
    "url": "https://github.com/owner/name",
    "stars": 12345,
    "reason": "一句话推荐理由"
  }
]
```

如果今天没有值得推荐的仓库，输出空数组 `[]`。

> 注意：仅输出推荐列表，不要 clone 或分析仓库。深度研究由独立流程执行。

## 任务 3：更新 Agent 记忆

读取 `CLAUDE.md` 末尾的「Agent 记忆」区域，根据本次执行情况更新：

- **搜索策略** — 哪些数据源质量高/低、哪些关键词有效、过滤规则调整
- **趋势追踪** — 本次发现的新趋势、持续升温的话题、值得长期关注的项目
- **执行日志** — 本次执行摘要（日期、采集条数、日报亮点），只保留最近 7 条

> 注意：只更新「Agent 记忆」部分，不要修改 CLAUDE.md 的其他内容。
