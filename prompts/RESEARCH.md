# AI Daily Paper — 仓库深度研究

> 此 prompt 由 research.sh 按仓库并行调用，每次只研究一个仓库。

## 研究方式

通过 GitHub API 获取信息（不要 clone），包括：
- 仓库元信息（star/fork/issue/语言）
- README 全文
- 目录结构
- 最近提交记录

## 分析维度

1. **项目概述** — 一句话说明
2. **技术栈** — 语言、框架、核心依赖
3. **项目结构** — 关键目录和文件
4. **核心功能** — 详细展开每个模块的设计思路
5. **活跃度** — 提交频率、contributor、issue/PR
6. **亮点与不足** — 值得学习的设计 + 潜在问题
7. **应用方向分析**（重点）：
   - 该项目解决了什么核心痛点
   - 适合哪些具体业务场景（举例说明）
   - 可以与哪些技术/项目结合使用
   - 对个人开发者 vs 企业分别有什么价值
   - 潜在的二次开发或扩展方向
