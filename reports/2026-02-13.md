## 📄 论文精选

**AIR：首个 LLM Agent 事件响应框架**
针对 Agent 安全的"事后响应"空白，AIR 提出首个事件响应框架，定义了管理 Agent 事件生命周期的领域特定语言，覆盖检测、遏制和恢复全流程。当前 Agent 安全研究几乎全部聚焦于"预防"，AIR 填补了"事件发生后怎么办"的关键缺口——考虑到今日两起真实失控事件，这一研究方向的紧迫性不言而喻。[ArXiv 2602.11749, 作者：Zibo Xiao, Jun Sun, Junjie Chen]

**AgentLeak：多 Agent 系统隐私泄露的全栈基准**
当多个 Agent 协作执行任务时，敏感数据通过 Agent 间消息、共享内存和工具参数等内部通道传递，而现有审计方法只检查最终输出。AgentLeak 提出首个覆盖内部通道的全栈隐私泄露基准，涵盖医疗、金融、法律和企业四大领域的 1,000 个场景。随着多 Agent 系统从实验走向生产，内部通道的隐私风险将成为合规的核心挑战。[ArXiv 2602.11510, 作者：Faouzi El Yagoubi, Ranwa Al Mallah, Godwin Badu-Marfo]

**When Agents Disagree With Themselves：Agent 行为一致性的量化研究**
对同一 LLM Agent 执行同一任务两次，行为是否一致？在 3,000 次 Agent 运行（Llama 3.1 70B、GPT-4o、Claude Sonnet 4.5）的研究中，ReAct 风格 Agent 平均每 10 次运行产生 2.0-4.2 种不同的行动序列。行为一致的任务（≤2 种路径）准确率达 80-92%，而高度不一致的任务准确率骤降至 28-52%。这为 Agent 可靠性提供了可量化的预测指标。[ArXiv 2602.11619, 作者：Aman Mehta]

## 🤖 模型动态

**GLM-5：likes 持续增长但下载量停滞**

OpenBMB 发布 MiniCPM-SALA（524 likes，117 下载），基于 MiniCPM 架构的新变体。与 MiniCPM-o-4.5（1,007 likes，40K+ 下载）相比，SALA 刚刚起步。OpenBMB 持续在多模态小模型赛道密集布局。[HF]

**Voxtral Realtime：Mistral 的流式语音识别模型**
Mistral 发布 Voxtral-Mini-4B-Realtime（496 likes，4,541 下载），配套论文同日发布（ArXiv 2602.11298）。这是首个原生流式 ASR 模型，在亚秒延迟下匹配离线转录质量，支持 12 种语言。实时语音交互正从大模型附加功能演变为独立的模型赛道。[HF, ArXiv]
