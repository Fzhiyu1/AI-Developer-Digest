## 📄 论文精选

**CLI-Gym：通过环境反转生成 CLI 任务**
提出 Agentic Environment Inversion 方法，让 Agent 模拟和探索环境历史，自动生成命令行交互任务（如依赖解决、系统问题修复）。基于 Dockerfile 与 Agent 任务的类比，为环境密集型任务的规模化获取提供新思路。这解决了 Agent 编码能力评估中环境交互任务稀缺的问题。[ArXiv 2602.10999, 作者：Yusong Lin, Haiyang Wang, Shuzhe Wu 等]

**GameDevBench：通过游戏开发评估 Agent 能力**
首个结合软件开发复杂性与深度多模态理解的评估基准。Agent 需在大型密集代码库中导航，同时操作着色器、精灵图、动画等多模态资产。游戏开发场景天然要求代码与视觉场景的协同理解，为多模态编码 Agent 提供理想测试床。[ArXiv 2602.11103, 作者：Wayne Chi, Yixiong Fang, Arnav Yayavaram 等]

**FormalJudge：Agent 监督的神经符号范式**
针对 LLM-as-a-Judge 的根本困境（概率系统如何可靠监督其他概率系统），提出形式化验证方法。通过将自然语言规范翻译为形式化约束，为高风险领域的 Agent 行为安全提供原则性解决方案。这标志着 Agent 评估从"能做什么"转向"如何确保安全"。[ArXiv 2602.11136, 作者：Jiayi Zhou, Yang Sheng, Hantao Lou 等]
