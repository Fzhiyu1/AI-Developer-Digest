## 项目简介

Nous Research 出品的开源 AI Agent 框架，支持接入 Claude、GPT、Codex 等多种模型。定位是"随你成长的 Agent"——通过持续学习用户习惯和偏好，提供越来越个性化的 AI 协作体验。

## 核心特性

- **多模型支持**：Claude Code、OpenAI Codex、OpenClaw 等均可接入
- **持久记忆**：Agent 跨会话保留上下文和用户偏好
- **工具生态**：内置代码执行、文件操作、网络搜索等工具
- **Hermes 协议**：自研的 Agent 间通信协议，支持多 Agent 协作

## 为什么值得关注

Nous Research 以高质量模型微调和开源贡献著称（Hermes 系列模型）。这个 Agent 框架延续了他们的开源精神，且与 OpenClaw 生态有深度集成（标签中明确列出 `openclaw`）。对于想构建自定义 AI Agent 的开发者，值得重点关注。

## 快速开始

```bash
pip install hermes-agent
hermes init
hermes run --model claude
```
