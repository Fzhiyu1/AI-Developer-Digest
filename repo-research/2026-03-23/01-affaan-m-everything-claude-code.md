## 它是什么
面向 Claude Code、Codex、Cursor 等代理编程工作流的“增强层”，核心卖点不是单一功能，而是把 skills、memory、security、hooks、持续学习和编排规范打包成一套生产化方法论。

## 为什么今天值得关注
AI agent harness 性能优化系统 这个方向，正好踩中今天 AI 开发生态的高频主题：大家已经不只是追新模型，而是在补齐“执行层”“工作流层”“配套层”。这类仓库能冲到 GitHub 热门前列，说明需求非常现实，而且不再局限于 demo。

## 我看到的核心价值
1. 顺应 agent coding 从“能用”走向“优化和治理”的趋势
2. 适合团队把零散提示词/脚本沉淀为制度化工作流
3. 高 star 说明开发者对“如何更好地使用 coding agent”有强烈需求

## 风险 / 局限
1. 系统较重，接入门槛高于单一插件
2. 强依赖具体 harness 生态，迁移成本不可忽视
3. 安全/自动化能力越强，越需要审计和边界控制

## 后续观察点
1. Selective install / state store / orchestration 等能力是否稳定演进
2. 是否形成跨团队可复用的最佳实践标准
3. 与原生 Claude Code/Codex 能力的重叠与替代关系

## 一句话判断
everything-claude-code 的爆红，不只是“它做得酷”，而是因为它代表了一个更大的方向：**AI 工具正在从模型能力竞争，转向工作流、执行层和商业交付能力竞争。**
