## 项目概述

RuView 是一个突破性的 WiFi 感知系统，能够将普通 WiFi 信号转换为实时人体姿态估计、生命体征监测和存在检测 — **完全不需要摄像头、可穿戴设备或互联网连接**。

### 核心技术

通过分析 WiFi 信道状态信息（CSI）中由人体运动引起的扰动，系统使用基于物理的信号处理和机器学习重建：
- 身体位置（17 个关键点）
- 呼吸频率（6-30 次/分钟）
- 心率（40-120 次/分钟）

## 技术亮点

### 1. 隐私优先设计
- **零视频数据**: 完全基于 WiFi 信号，不存储任何图像
- **合规友好**: 避开 GDPR 视频监控和 HIPAA 影像规定
- **无需同意**: 不涉及面部识别或个人图像采集

### 2. 穿墙能力
- WiFi 信号可穿透墙壁、家具和碎片
- 适用于摄像头无法工作的场景（灾难救援、黑暗环境）
- 穿墙深度可达 5 米

### 3. 多人追踪
- 同时追踪多人，每人独立姿态和生命体征
- 单个 AP 可区分 3-5 人（56 个子载波）
- 多 AP 网格线性扩展（4 个 AP 可覆盖 15-20 人）

### 4. 极致性能
- **810 倍加速**: 完整 Rust 重写，54,000 帧/秒处理速度
- **超小体积**: 132 MB Docker 镜像
- **边缘运行**: 完全在 $9 ESP32 芯片上运行，无需云服务

## 架构设计

### 信号处理流程

```
WiFi 路由器 → 房间内无线电波 → 人体散射
    ↓
ESP32 网格（4-6 节点）通过 TDM 协议捕获 CSI
    ↓
多频段融合：3 频道 × 56 子载波 = 168 虚拟子载波
    ↓
多基站融合：N×(N-1) 链路 → 注意力加权跨视角嵌入
    ↓
相干门控：接受/拒绝测量 → 数天稳定无需调优
    ↓
信号处理：Hampel、SpotFi、Fresnel、BVP、频谱图
    ↓
AI 骨干（RuVector）：注意力、图算法、压缩、场模型
    ↓
神经网络：处理信号 → 17 个身体关键点 + 生命体征
```

### 自学习系统（ADR-024）

- **无监督学习**: 从原始 WiFi 数据自我训练，无需标注数据集
- **跨环境泛化**: 一次训练，任意房间部署
- **模型大小**: 仅 55 KB（可在 ESP32 上运行）
- **128 维指纹**: 每个 WiFi 信号生成唯一环境指纹

## 应用场景

### 医疗健康
- **老年护理**: 跌倒检测、夜间活动监测、睡眠呼吸监测

- **搜救**: 通过瓦砾检测幸存者呼吸特征

- **协作机器人安全区**: 检测障碍物后人类存在，自动减速
- **仓库 AMR 导航**: 感知盲角处的人类
- **人形机器人空间感知**: 无需始终开启摄像头的姿态感知

## 技术栈

### 硬件支持
- **ESP32-S3 网格**（推荐）: 3-6 个节点，约 $54
- **研究网卡**: Intel 5300 / Atheros AR9580
- **普通 WiFi**: 仅支持 RSSI 粗略存在检测

### 软件架构
- **主要语言**: Rust（810 倍性能提升）
- **传统支持**: Python（遗留 v1 API）
- **推理引擎**: ONNX、PyTorch、Candle
- **边缘运行时**: WASM3（ESP32 上的 WebAssembly）

### 部署方式
- **Docker**: 一键启动（30 秒内实时感知）
- **源码编译**: Rust 或 Python
- **浏览器**: WASM 浏览器内执行
- **IoT**: ESP32 传感器网格
