## 项目概述

AFFiNE 是一个隐私优先、本地优先的开源知识库平台,定位为 Notion 和 Miro 的替代品。它将文档、画布和表格融合在一个统一的工作空间中。

**核心理念**: 超越 Notion 和 Miro,将规划、整理和创作融为一体。

---

## 核心特性

### 1. 超融合工作空间
- **文档 + 画布 + 表格** 完全融合
- 任何块都可以放在无边界画布上
- 富文本、便签、嵌入网页、多视图数据库、链接页面、形状、幻灯片

### 2. 多模态 AI 伙伴
- 撰写专业工作报告
- 将大纲转换为演示幻灯片
- 将文章总结为思维导图
- 整理工作计划和任务
- 直接绘制和编码原型应用

### 3. 本地优先 + 实时协作
- 数据始终存储在本地磁盘
- 支持实时同步和协作
- Web 和跨平台客户端

### 4. 自托管 + 可定制
- 完全自由管理和自托管
- 可 fork 和构建自己的版本
- 插件社区即将推出

## 技术架构

### 核心技术栈
- **TypeScript** - 主要开发语言
- **React** - UI 框架
- **Electron** - 桌面应用
- **Jotai** - 状态管理
- **Vite** - 构建工具

### 底层引擎
- **BlockSuite** - 协作编辑器项目
- **y-octo** - 原生高性能 YJS CRDT 实现 (Rust)
- **OctoBase** - 本地优先数据库 (Rust)
- **yjs** - CRDT 状态管理和数据同步

### 跨平台支持
- Web 应用
- macOS / Windows / Linux 桌面
- 移动端 (开发中)

## 挑战与机遇

### 挑战

3. **用户习惯** - 迁移成本较高
4. **移动端** - 移动应用仍在开发

1. **隐私意识** - 用户越来越重视数据隐私
2. **开源趋势** - 开源工具接受度提升
3. **AI 浪潮** - AI 原生应用需求增长

## 总结

AFFiNE 代表了知识管理工具的新方向 - 本地优先、开源透明、AI 原生。它不仅是 Notion 的替代品,更是对"知识工作空间"的重新思考。

通过将文档、画布、表格融合在一起,AFFiNE 提供了更灵活的知识组织方式。基于 CRDT 的协作能力和 Rust 性能引擎,确保了出色的用户体验。

65K+ 的 GitHub Stars 证明了社区对这一理念的认可。随着功能的完善和生态的建设,AFFiNE 有望成为开源知识管理领域的标杆项目。
