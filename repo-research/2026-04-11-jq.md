## 📋 项目概述

jq 是一个轻量级、灵活的命令行 JSON 处理器，类似于 JSON 数据的 sed/awk/grep。用可移植 C 编写，零运行时依赖，可轻松对结构化数据进行切片、过滤、映射和转换。

---

## 🚀 核心特性

- **零依赖**: 纯 C 实现，无运行时依赖
- **跨平台**: 可移植，支持所有主流操作系统
- **强大的查询语言**: 内置完整的 JSON 处理 DSL
- **管道友好**: 完美融入 Unix 管道工作流
- **在线试用**: play.jqlang.org

## 💡 常用场景

### 基础过滤

```bash
# 提取字段
echo '{"name":"Alice","age":30}' | jq '.name'
# 输出: "Alice"

# 数组索引
echo '[1,2,3]' | jq '.[1]'
# 输出: 2

# 嵌套字段
cat data.json | jq '.user.address.city'
```

### 数组操作

```bash
# 过滤数组
cat users.json | jq '.[] | select(.age > 25)'

# 映射转换
cat users.json | jq '[.[] | {name: .name, email: .email}]'

# 排序
cat data.json | jq 'sort_by(.score) | reverse'
```

### 与 AI 工具链集成

```bash
# 处理 OpenAI API 响应
curl https://api.openai.com/v1/chat/completions \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -d '{"model":"gpt-4","messages":[{"role":"user","content":"hello"}]}' \
  | jq '.choices[0].message.content'

# 批量处理 LLM 输出
cat responses.jsonl | jq -r '.content' | while read line; do
  echo "$line"
done
```

### 数据管道

```bash
# 从 API 提取并转换
curl api.example.com/data | jq '[.items[] | {id, title, score: .metrics.score}]'

# 合并多个 JSON 文件
jq -s '.[0] * .[1]' config.json overrides.json
```

## 🎯 在 AI 开发中的价值

随着 AI 应用的普及，JSON 成为 LLM API 的通用数据格式。jq 在以下场景中不可或缺：

1. **API 响应处理**: 快速提取 LLM API 返回的内容
2. **数据集处理**: 处理 JSONL 格式的训练数据
3. **配置管理**: 处理 AI 工具的 JSON 配置文件
4. **日志分析**: 分析 AI 应用的结构化日志
5. **脚本自动化**: 在 shell 脚本中处理 AI 工作流数据

---

## 🏆 为何在 AI 时代重新走红

jq 是一个已有十余年历史的成熟工具，但在 AI 开发浪潮中重新获得关注：

- **LLM API 全部返回 JSON**: OpenAI、Anthropic、Google 等 API 均使用 JSON
- **Agent 工作流需要数据处理**: 复杂 Agent 管道中大量 JSON 转换需求
- **MCP 协议基于 JSON**: Model Context Protocol 的数据交换格式
- **JSONL 训练数据**: 微调数据集普遍使用 JSONL 格式

**总结**: jq 是每个 AI 开发者工具箱中的必备工具。在 LLM API 和 Agent 工作流主导的今天，高效处理 JSON 数据的能力比以往任何时候都更重要。
