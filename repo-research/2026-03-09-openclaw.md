## 项目概述

OpenClaw 是一个开源的个人 AI 助手平台,允许用户在自己的设备上运行 AI 助手。它的核心理念是"本地优先、快速响应、始终在线",为用户提供真正属于自己的 AI 助手体验。

**核心定位**: 跨平台个人 AI 助手控制平面

---

## 技术架构

### 核心组件

1. **Gateway (控制平面)**
   - WebSocket 控制平面 (ws://127.0.0.1:18789)
   - 统一管理会话、频道、工具和事件
   - 支持 launchd/systemd 守护进程模式

2. **多渠道接入**
   - 支持 20+ 消息平台: WhatsApp, Telegram, Slack, Discord, Google Chat, Signal, iMessage, BlueBubbles, IRC, Microsoft Teams, Matrix, Feishu, LINE, Mattermost, Nextcloud Talk, Nostr, Synology Chat, Tlon, Twitch, Zalo, WebChat 等
   - 统一的消息路由和会话管理

3. **跨平台客户端**
   - macOS 菜单栏应用
   - iOS/Android 节点应用
   - CLI 工具
   - Web 控制台

4. **AI 代理运行时**
   - Pi agent (RPC 模式)
   - 工具流式传输
   - 块流式传输

## 核心特性

### 1. 本地优先 + 实时协作
- 数据始终存储在本地磁盘
- 支持跨平台实时同步

### 6. 技能平台
- 捆绑技能 (bundled)

- ClawHub 技能注册中心

## 安全设计

### DM 配对机制
- 默认 `dmPolicy="pairing"` - 未知发送者需要配对码
- 通过 `openclaw pairing approve` 批准
- 公开 DM 需显式设置 `dmPolicy="open"`

### 沙盒隔离
- 主会话默认完全访问
- 群组/频道会话可运行在 Docker 沙盒中
- 工具白名单/黑名单机制

### Tailscale 集成
- Serve 模式: tailnet 内部 HTTPS
- Funnel 模式: 公网 HTTPS (需密码认证)
- 强制 loopback 绑定

## 部署方式

### 1. 快速安装 (推荐)
```bash
npm install -g openclaw@latest
openclaw onboard --install-daemon
```

### 2. 从源码构建
```bash
git clone https://github.com/openclaw/openclaw.git
cd openclaw
pnpm install
pnpm ui:build
pnpm build
pnpm openclaw onboard --install-daemon
```

### 3. Docker 部署
- 支持自托管
- 可在小型 Linux 实例上运行
- 客户端通过 Tailscale/SSH 连接

### 4. Nix 声明式配置
- 支持 Nix 模式
- 声明式配置管理
