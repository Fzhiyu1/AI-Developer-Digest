# cheahjs/free-llm-api-resources

> 研究日期：2026-02-14

## 1. 项目概述

一个社区维护的免费 LLM API 资源清单，汇总了所有提供免费推理额度或试用积分的 API 服务商，并通过 GitHub Actions 自动拉取各平台最新可用模型列表。

## 2. 技术栈

- 语言：Python（100%）
- 自动化：GitHub Actions（定时触发 README 更新）
- 依赖：`requests`、`google-cloud-aiplatform`、`beautifulsoup4`（见 `src/requirements.txt`）
- 数据源：直接调用各服务商 API 获取可用模型列表
- 部署：GitHub Pages 静态展示

## 3. 项目结构

```
├── README.md                          # 自动生成的免费 LLM API 清单（核心产出）
├── src/
│   ├── pull_available_models.py       # 模型拉取脚本（41KB，核心逻辑）
│   ├── data.py                        # 服务商元数据定义（限流规则、分类等）
│   ├── README_template.md             # README 模板
│   ├── requirements.txt               # Python 依赖
│   └── 1-second-of-silence.mp3        # Groq Whisper API 测试用音频
├── .github/
│   ├── workflows/
│   │   ├── update-readme.yml          # 定时更新 README 的 CI
│   │   └── readme-change-validator.yml # PR 校验工作流
│   └── pull_request_template.md       # PR 模板
└── .gitignore
```

项目极简——核心就是一个 Python 脚本 + 一个 README。`pull_available_models.py`（41KB）是整个项目的大脑，负责调用 OpenRouter、Google AI Studio、NVIDIA NIM、Mistral、HuggingFace、Cerebras、Groq、Cohere、GitHub Models、Cloudflare Workers AI、Vertex AI 等十余个平台的 API，拉取当前可用的免费模型列表，然后渲染到 README。

## 4. 核心功能

### 4.1 多平台模型自动采集

`src/pull_available_models.py` 实现了对 14+ 个 LLM 服务商的 API 调用，自动获取当前免费可用的模型列表。每个平台有独立的采集逻辑，处理不同的 API 格式和认证方式。README 顶部标注：

```
WARNING: DO NOT EDIT THIS FILE DIRECTLY. IT IS GENERATED BY src/pull_available_models.py
```

### 4.2 结构化限流信息

不仅列出模型名称，还详细记录每个平台的限流规则。例如 Cerebras 的表格精确到 requests/minute、tokens/minute、requests/hour、tokens/hour、requests/day、tokens/day 六个维度。这是手动维护的 awesome-list 难以做到的。

### 4.3 CI 自动更新

通过 `update-readme.yml` 工作流定时运行 `pull_available_models.py`，自动创建 PR 更新 README。从提交历史看，自动更新频率约为每周一次。`readme-change-validator.yml` 则校验社区提交的 PR 是否符合格式要求。

## 6. 亮点与不足

### 亮点

1. **自动化程度高**：通过 Python 脚本直接调用各平台 API 获取实时模型列表，而非手动维护，数据准确性远超普通 awesome-list。README 由脚本生成，减少人为错误
2. **信息密度大**：覆盖 14 个免费平台 + 14 个试用积分平台，每个平台附带精确的限流规则、注册要求、模型列表，是目前同类资源中最全面的
3. **明确排除非法服务**：README 显著标注"This list explicitly excludes any services that are not legitimate (eg reverse engineers an existing chatbot)"，维护了清单的可信度

### 不足

1. **单人维护风险**：251 次提交中仅 cheahjs 一人贡献实质代码，且最近一次手动提交在 2025-12-17（距今近 2 个月）。社区 PR 响应缓慢，#276 自动更新 PR 已开放 11 天未合并
2. **无许可证**：仓库未设置任何开源许可证（license 字段为 null），这意味着默认版权保留，其他项目引用或 fork 存在法律风险
3. **缺乏验证机制**：脚本拉取模型列表后直接渲染，没有对服务可用性的实际验证（如发送测试请求确认模型真的可用）。平台下线模型或调整限流后，可能存在信息滞后

## 8. 应用方向分析

### 核心痛点

LLM API 服务商众多，免费额度政策分散在各自官网，开发者需要逐一注册、查阅文档才能找到适合自己的免费方案。本项目将这些信息聚合到一个页面，消除了信息不对称。

### 最佳应用场景

**场景一：个人开发者原型验证**

独立开发者在构建 AI 应用原型时，通常不愿在验证阶段投入 API 费用。本清单提供了一个按平台分类的免费资源地图：OpenRouter 50 请求/天适合低频测试，Google AI Studio 14,400 请求/天适合中等规模实验，Cerebras 14,400 请求/天 + 高速推理适合需要快速迭代的场景。开发者可以根据自己的用量需求快速定位最合适的免费平台，而不是盲目注册所有服务。

**场景二：教育和教学**

AI 课程教师需要为学生提供免费的 API 访问。本清单的限流信息可以帮助教师评估哪个平台能支撑一个班级的并发使用——例如 Mistral 的 100 万 tokens/分钟免费额度足以支撑小班教学，而 Cloudflare Workers AI 的 10,000 neurons/天可能不够。

### 其他场景

- CI/CD 中集成 LLM 质量检查（需要免费且稳定的 API）
- 多模型对比评测（利用多个免费平台同时测试）

### 对个人开发者的价值

省去逐一调研各平台免费政策的时间成本。清单中的限流信息帮助开发者在项目初期就规划好 API 用量，避免开发到一半发现免费额度不够用。对于预算有限的独立开发者，试用积分部分（Baseten $30、Modal $30/月）提供了更大的实验空间。

### 对企业的价值

企业价值有限。免费额度的限流规则（如 OpenRouter 50 请求/天、Cohere 1,000 请求/月）无法支撑生产环境。但对企业内部的 AI 技术选型团队有参考价值——可以通过免费额度快速评估各平台的 API 设计、响应速度和模型质量，再决定付费采购哪家。
