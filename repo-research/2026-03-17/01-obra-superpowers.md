# 01. obra/superpowers

- **仓库地址**：<https://github.com/obra/superpowers>
- **当前热度**：约 88.6k stars（采集时）
- **一句话概览**：一个面向 agent 的 skills 框架与软件开发方法论仓库，强调把能力、流程与约束封装为可组合技能。

## 我为什么关注它
- 把 AI coding 从“问答式助手”推进到“技能化、流程化交付”
- 适合团队沉淀可复用 SOP，而不是依赖个人 prompt 手感
- 对 OpenClaw / Claude Code / Codex 这类 agent 生态都有参考意义

## 对 AI 开发者的启发
1. **工程重心正在上移**：大家关注的不再只是模型效果，而是技能组织、记忆管理、协作范式这些更接近“系统层”的问题。
2. **可复用资产比一次性 prompt 更值钱**：无论是 superpowers 这类 skills，还是 claude-mem 这类 memory，都在把 AI 使用经验沉淀成长期资产。
3. **单 agent 不一定是终点**：MiroFish 代表的群体智能路线提醒我们，未来 agent 系统可能是多策略、多模块协作，而不是一个大模型包打天下。

## 建议后续跟踪
- skills 目录组织方式
- skill 之间的依赖管理
- 是否形成社区标准化接口
