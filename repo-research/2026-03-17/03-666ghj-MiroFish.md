# 03. 666ghj/MiroFish

- **仓库地址**：<https://github.com/666ghj/MiroFish>
- **当前热度**：约 30.0k stars（采集时）
- **一句话概览**：一个主打“预测万物”的简洁群体智能引擎，尝试把 swarm intelligence 做成通用决策/预测底座。

## 我为什么关注它
- 不是典型 AI wrapper，更偏系统与方法层创新
- 反映社区还在探索多智能体、群体协作式推理的更一般范式
- 如果能和 LLM agent 结合，可能形成“语言推理 + 群体搜索/优化”的混合架构

## 对 AI 开发者的启发
1. **工程重心正在上移**：大家关注的不再只是模型效果，而是技能组织、记忆管理、协作范式这些更接近“系统层”的问题。
2. **可复用资产比一次性 prompt 更值钱**：无论是 superpowers 这类 skills，还是 claude-mem 这类 memory，都在把 AI 使用经验沉淀成长期资产。
3. **单 agent 不一定是终点**：MiroFish 代表的群体智能路线提醒我们，未来 agent 系统可能是多策略、多模块协作，而不是一个大模型包打天下。

## 建议后续跟踪
- 真实 benchmark 与案例
- 是否有清晰 API/SDK
- 能否从概念热度走向可复用工程能力
