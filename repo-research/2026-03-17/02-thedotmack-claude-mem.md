# 02. thedotmack/claude-mem

- **仓库地址**：<https://github.com/thedotmack/claude-mem>
- **当前热度**：约 36.8k stars（采集时）
- **一句话概览**：一个面向 Claude Code 的记忆插件，自动记录会话行为、压缩成可复用记忆，并在后续任务中回注上下文。

## 我为什么关注它
- 直接命中 AI coding 的“长任务失忆”痛点
- memory 压缩与检索会成为 agent 基础设施的重要层
- 如果这类方案成熟，未来 IDE agent 的差异化会越来越多地体现在记忆管理而非模型本身

## 对 AI 开发者的启发
1. **工程重心正在上移**：大家关注的不再只是模型效果，而是技能组织、记忆管理、协作范式这些更接近“系统层”的问题。
2. **可复用资产比一次性 prompt 更值钱**：无论是 superpowers 这类 skills，还是 claude-mem 这类 memory，都在把 AI 使用经验沉淀成长期资产。
3. **单 agent 不一定是终点**：MiroFish 代表的群体智能路线提醒我们，未来 agent 系统可能是多策略、多模块协作，而不是一个大模型包打天下。

## 建议后续跟踪
- 记忆压缩质量
- 注入时机是否稳定
- 是否会引入错误记忆污染
