# obra/superpowers 研究

- 仓库：<https://github.com/obra/superpowers>
- 定位：面向 AI coding agent 的“技能框架 + 软件开发方法论”
- 当前热度：95k+ stars（日报采集快照）

## 它是什么
README 的核心表述很明确：这不是单个脚本工具，而是一整套面向 coding agent 的开发工作流。它强调：
- 先澄清需求与规格；
- 再形成可执行计划；
- 之后由子代理推进实现；
- 全程配合 skills 自动触发。

## 为什么会火
1. **击中当前 AI 编程的真实痛点**：大家不是缺一个更会写代码的模型，而是缺一套“不容易跑偏”的执行框架。
2. **把 prompt 经验产品化**：把高手经验变成可复用插件/技能，而不是只存在推特线程里。
3. **贴合 Claude Code / Codex / OpenCode 等生态**：README 直接给出多平台安装说明，传播效率高。

## 对开发者的意义
- 说明 agent coding 已经进入“流程工程”阶段。
- 团队未来的竞争力，不只是选哪个模型，而是谁先把 spec、plan、review、subagent orchestration 规范化。
- 很可能带动一波“AI 原生工程管理”工具出现。

## 风险/局限
- 方法论越完整，学习成本越高。
- 过强的流程可能降低轻量任务效率。
- 很依赖底层 agent 的稳定性与工具执行质量。

## 结论
`superpowers` 的爆红，不只是因为它会装插件，而是因为它在回答一个更大的问题：**怎么把 LLM 从“会写代码”变成“能参与工程协作”。**
