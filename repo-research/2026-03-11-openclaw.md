## 项目概述

OpenClaw 是一个跨平台的个人 AI 助手框架，口号是"Your own personal AI assistant. Any OS. Any Platform. The lobster way. 🦞"。这个项目以其独特的"龙虾方式"设计哲学和极高的 GitHub 星标数成为 AI 助手领域的标杆项目。

## 核心特性

### 跨平台支持
- 支持所有主流操作系统（Windows、macOS、Linux）
- 统一的 API 接口，一次编写，到处运行
- 轻量级架构，适配从树莓派到服务器的各种硬件

### "龙虾方式"哲学
项目采用独特的"lobster way"设计理念，强调：
- **去中心化**: 数据和控制权完全属于用户
- **模块化**: 可插拔的技能系统
- **适应性**: 像龙虾一样能在各种环境中生存

### 技能系统
- 开放的技能市场
- 社区贡献的技能包
- 支持自定义技能开发

## 技术架构

### 核心组件
1. **Gateway**: 中央协调器，管理会话和路由
2. **Skills Framework**: 技能加载和执行引擎
3. **MCP Integration**: 支持 Model Context Protocol
4. **Multi-Agent System**: 子代理编排能力

### 安全特性
- 本地优先的数据处理
- 细粒度的权限控制
- 沙箱执行环境

4. **社区驱动**: 快速迭代，响应用户需求
