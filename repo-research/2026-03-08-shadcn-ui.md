## 📋 项目概述

shadcn/ui 是一套精美设计的可访问组件集和代码分发平台,支持多种主流框架。它不是传统的组件库,而是一个可定制、可扩展的组件系统。

**核心理念**: Open Source. Open Code. - 开源代码,开放使用。

---

## 🎯 核心特性

### 1. 设计精美
- 现代化的 UI 设计
- 注重细节和用户体验
- 符合可访问性标准

### 2. 高度可定制
- 不是 npm 包,而是代码分发
- 组件代码直接复制到项目中
- 完全控制和自定义能力

### 3. 框架无关
- 支持 React、Vue、Svelte 等主流框架
- 灵活的集成方式
- 适配不同技术栈

### 4. 开放架构
- 可以作为构建自己组件库的基础
- 鼓励二次开发和扩展
- 社区驱动的生态系统

## 💡 技术亮点

### 代码分发模式
与传统组件库不同,shadcn/ui 采用代码分发模式:
- 组件代码直接添加到项目中
- 开发者拥有完全控制权
- 无需担心版本锁定和依赖冲突
- 可以根据需求自由修改

### 可访问性优先
- 遵循 WAI-ARIA 标准
- 键盘导航支持
- 屏幕阅读器友好
- 符合 WCAG 指南

### 现代化工具链
- 基于 Radix UI 原语
- 使用 Tailwind CSS 样式
- TypeScript 类型支持
- 完善的文档系统
